# Marbella 2027

Entscheidungsgrundlage für die Golfwoche vom 5.–9. Mai 2027: sechs Airbnb-Objekte
in und um Marbella im Vergleich — Karte, Preise, Bewertungen, Ausstattung und
echte Fahrdistanzen zu allen vier Golfplätzen des Programms.

**Seite:** https://hilfsscheriff.github.io/marbella-2027/

## Inhalt

- `index.html` — die komplette Seite, eine Datei, ohne Build-Schritt

## Woher die Daten stammen

| Angabe | Quelle |
|---|---|
| Ausstattung, Bewertungen, Kapazität, Hausregeln | Airbnb-Inserate, abgerufen am 12.09.2026 |
| Preise | WhatsApp-Umfrage der Gruppe, unverändert übernommen |
| Fahrdistanzen | OSRM auf OpenStreetMap-Daten, echte Strassenrouten ohne Verkehr |
| Küstenlinie der Karte | OpenStreetMap (Overpass) |
| Golfplatz-Koordinaten | OpenStreetMap |

Airbnb zeigt Standorte bewusst rund 150 m ungenau — die Karte stimmt auf
Quartierebene, nicht auf die Hausnummer.

## Offene Punkte

Die Zuordnung zweier Preise aus der Umfrage ist noch ungeklärt, ebenso der
Anreisetag (im Golfsheet steht «Mittwoch, 8.05.», der 8. Mai 2027 ist aber ein
Samstag). Beides ist auf der Seite unter «Vor dem Entscheid abklären» notiert.
